# 東洋ケアラボ｜東洋医学体質チェック（試作版 v0.1）

16問・8体質傾向の簡易スコア、五行参考表示、セルフケアと参考経穴、サーバー認証付き専門家情報、Netlify Forms感想フォームを含みます。**医療用診断システムではありません。臨床監修・妥当性検証は未実施です。**

## 公開手順

1. ZIPを展開し、**フォルダ内のファイルとフォルダ一式**を新規GitHubリポジトリのルートにアップロード。既存の五行神獣アプリとは別リポジトリにする。
2. Netlifyで新規サイトを作成し、GitHubリポジトリを連携。`netlify.toml` がビルド条件を指定する（build: `npm run build`、publish: `dist`）。
3. Netlifyのサイト環境変数 `PRO_ACCESS_KEY` に推測されにくい長いアクセスキーを設定し、再デプロイする。**鍵をGitHubに保存しない。** 共有鍵方式は試作向けであり、本番の専門家課金には個人アカウント・サーバー側認可・失効機能が必要。
4. Publishedを確認し、公開URLで16問回答・結果・専門家キー成功/失敗・感想送信を試す。
5. Netlify管理画面のForms一覧で`feedback`にテストデータが**実際に保存されたこと**を確認する。フォーム認識に失敗する場合はNetlifyのフォーム検出設定・デプロイログ・公開HTMLを確認。
6. スマホ実機でタップ・レイアウト・画面遷移を確認する。

## 設計上の注意

- 質問は独自の簡易的な設問で、尺度の妥当性・臨床精度は未検証。診断名を確定しない。
- 八綱の寒熱、虚実や舌・脈所見による弁証は**未実装**。結果画面の専門家表示は1体質→代表的な候補の例示に限る。
- ツボの位置は目安の文章表示。解剖学的・専門的な取穴図の監修と画像は未実装。
- 鍼や灸の自己施術は案内しない。妊娠中や症状がある場合の自己判断による強刺激を避ける。
- 回答内容はブラウザ内で計算し、保存・送信しない。感想だけNetlify Formsに送信する。症状や個人情報は記入しないよう案内。
- 開発環境：Node.js 18+、`npm test`、`npm run build`。ローカルの静的サーバーではFunctions/Formsは動作しない。Netlifyでの実動作は公開後に検証。
- **決済は未実装**。キー付き保護の動作も公開環境では未検証。
